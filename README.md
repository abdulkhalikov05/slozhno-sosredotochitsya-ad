# Сложно сосредоточиться

Учебный проект «Сложно сосредоточиться» (спринт по вёрстке).

Сайт с тёмной и светлой темами, адаптивной вёрсткой и переключателем тем в шапке.

## Технологии

- HTML5, CSS3
- Mobile First
- CSS-переменные, Grid, Flexbox
- `prefers-color-scheme`, классы `theme-light`, `theme-dark`, `theme-auto`

## Запуск проекта

Откройте `index.html` в браузере или выполните в корне проекта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## Структура

- `index.html` — разметка страницы
- `styles/` — стили (глобальные, темы, переменные)
- `fonts/` — шрифт IBM Plex Mono
- `images/` — изображения и фавиконки
- `scripts/script.js` — переключение темы
